# Vendor Governance Portal

A web application for managing vendor relationships, compliance, and risk assessments.

## Features

- **Dashboard** – Summary metrics: total vendors, annual spend, high-risk count, non-compliance count, and risk distribution chart.
- **Vendor List** – Browse all registered vendors with status, risk level, and spend at a glance.
- **Vendor Detail** – Full vendor profile including contact info, contract dates, compliance checklist, and risk assessment breakdown.
- **Register Vendor** – Validated form for onboarding new vendors with contract and risk details.

## Tech Stack

- [Next.js 16](https://nextjs.org/) (App Router, TypeScript)
- [Tailwind CSS](https://tailwindcss.com/)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm start
```
